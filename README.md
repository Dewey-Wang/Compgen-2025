# Introduction

This repository contains my notes and code for the "Compgen-2025" course, a comprehensive learning journey into computational genomics and related fields. Beyond documenting my studies, this repo also includes practical code implementations where I apply the knowledge gained from the course to real-world problems in genomics. The notes and code are organized from Notion and published on GitHub, with the goal of sharing valuable insights with the community. The course notes are hosted at the following URL:  

**Course Notes URL:** [https://dewey-wang.github.io/Compgen-2025/](https://dewey-wang.github.io/Compgen-2025/)

## Course Overview

The Compgen-2025 course, expertly led by **Dr. Altuna Akalın**, **Dr. Artür Manukyan**, **Dr. Bora Uyar**, and other outstanding instructors from the **Max Delbrück Center for Molecular Medicine (MDC)**, is designed for computational biology PhD students, experimental biologists, and medical scientists eager to enhance their skills in data analysis. The course blends theoretical lectures with hands-on programming exercises, primarily using R and Python. While my notes focus more on fundamental concepts and the reasoning behind each step rather than detailed code implementation, this repo also includes code where I apply these concepts to practical genomics problems, such as statistical analysis, machine learning, and spatial transcriptomics.


#### Week 1 Topics
- Statistics in Genomics
- Unsupervised Learning
- Supervised Learning

#### Week 2 Topics
- Introduction to Spatial Transcriptomics
- Spatial Transcriptomics Analysis
- Multiomics Integration
